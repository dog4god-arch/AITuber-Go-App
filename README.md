# AITuber-Go

**Web の管理画面ですべてを操作できる、感情豊かな AITuber 配信アプリです。**
実行ファイル 1 つで、管理画面・OBS 用オーバーレイ・AI の会話エンジン・配信サイトとの連携・予約配信がまとめて動きます。

> [!WARNING]
> **現在はテスト版です。** まだ十分にテストできていないため、不具合や、今後のバージョンで設定・動作が変わることがあります。
> - **Windows 版**: 開発中に使っていますが、すべての機能・組み合わせは確認できていません
> - **Linux 版**: 起動から AI の返事・音声・オーバーレイまで動いたという報告を 1 件いただいています。まだ確認できていない機能があります
> - **Mac 版**: **実機ではまったく動作確認をしていません。** 起動しない・一部の機能が動かないことがあります
>
> 大事な配信で使う前に、必ず手元で試してください。設定やデータ (`data` フォルダ) は、ときどきバックアップを取っておくことをおすすめします。
>
> 🙏 **テストにご協力いただけるとうれしいです。** 特に Mac・Linux をお使いの方の「起動できた」「ここが動かなかった」という報告は、それだけでとても助かります。くわしくは「[テストへのご協力のお願い](#テストへのご協力のお願い)」をご覧ください。

- 🎭 **アバター**: VRM / Live2D / 画像 1 枚から作る AITuber Puppet。表情・まばたき・視線・口パク・身振り・手を振るお見送り
- 💗 **感情表現**: AI が文ごとに感情を付け、表情・モーション・声色が切り替わります
- 🗣️ **音声合成**: AivisSpeech (無料・既定) / Aivis Cloud API / VOICEVOX / Irodori-TTS / Style-Bert-VITS2 / OpenAI / ElevenLabs など
- 🧠 **LLM**: Google Gemini (無料の API キーで使える・既定) / OpenAI / Anthropic Claude / Ollama / LM Studio などの OpenAI 互換
- 📺 **配信サイト**: YouTube Live (限定公開にも対応) / Twitch / ツイキャス / Kick のコメントを読んで返事をします
- 📰 **話題**: トレンドやニュース、会話の流れからテーマを決めて雑談します
- 🎬 **配信形態**: 雑談・歌枠・ゲーム実況・質問コーナー・朗読。BGM、予約配信、共演 (複数キャラ)、コラボ配信、縦長配信
- 🎥 **OBS なしでも配信できます**: ブラウザの「スタジオ」画面で画面を組み立て、YouTube / Twitch などへ配信・録画
- 💬 **ELYTH (AITuber 専用 SNS)**: 返信・タイムラインへのコメント・お題への投稿を AI が行います

## 起動

**Windows**: `aituber.exe` をダブルクリックします。黒い画面 (ログ) が開いたら、ブラウザで **http://127.0.0.1:8930/** を開きます (管理画面)。黒い画面を閉じるとアプリは終了します。
「Windows によって PC が保護されました」と出たときは、「詳細情報」→「実行」を押します。
毎回ブラウザも開きたいときは、`aituber.exe` のショートカットを作り、プロパティの「リンク先」の最後に ` -open` を付け足します。

**Mac**: ターミナルで展開したフォルダに移動し、次を実行します。
```bash
xattr -d com.apple.quarantine ./aituber   # 初回だけ (インターネットから入手したアプリの確認を外します)
./aituber -open
```

**Linux**:
```bash
./aituber -open
```

設定やデータは、起動したフォルダ (ダブルクリックなら実行ファイルと同じ場所) の `data` フォルダに保存されます。アプリを新しくするときは、実行ファイルだけを置き換えてください (`data` はそのまま使えます)。

| 起動オプション | 説明 |
|---|---|
| `-open` | 起動時に管理画面を開く |
| `-data フォルダ` | データの保存先 (既定 `data`) |
| `-listen アドレス` | 待ち受けアドレス (既定 `127.0.0.1:8930`) |

> 他のパソコンやスマホから管理画面を開く場合は `-listen 0.0.0.0:8930` で起動し、必ず管理画面の「システム」で管理パスワードを設定してください。

## はじめの設定

1. **音声合成**: [AivisSpeech](https://aivis-project.com/) (無料) をインストールして起動しておきます。管理画面の「音声合成」で声を選びます
2. **LLM**: [Google AI Studio](https://aistudio.google.com/apikey) で無料の API キーを作り、管理画面の「LLM」の「Google Gemini」に貼り付けます
3. **画面に表示**: OBS に「ブラウザソース」を追加し、URL `http://127.0.0.1:8930/overlay/`、幅 1920・高さ 1080 にします (縦長配信なら 1080・1920)。「OBS で音声を制御する」にチェックを入れます
4. **配信サイト**: 管理画面の「配信プラットフォーム」で YouTube などを有効にし、ダッシュボードで配信を始めます

くわしい使い方は、管理画面の「ヘルプ」(各画面右上の「?」) で読めます。

## 画像 1 枚からキャラクターを作るとき (AITuber Puppet)

管理画面の「モデル生成」で、キャラクターの立ち絵 1 枚から動くモデルを作れます。どんな絵でも動かせるわけではなく、**次の条件に合う絵**なら、ほぼ自動で自然に動きます。

- キャラクター 1 人の**全身・正面** (少なくとも腰まで)。首を傾けていない
- **目は開けて、隠さない** (前髪・眼鏡・手が目にかかっていない)
- **口は閉じる** (線で描かれた口)
- **腕は下ろして体から少し離す**。手に物を持たない
- 背景は**透過 PNG か無地** (白など 1 色)
- **アニメ・イラスト調**で、キャラクターの高さが 1000px 以上 (おすすめ 1500px 以上)

条件に合わない絵は、「AIで立ち絵を作る」で整えられます (OpenAI / Gemini の画像生成の API キーが必要です)。まばたきをもっと自然にしたいときは、**目を閉じた絵**を AI で作るか、自分で描いた差分を使えます。くわしくは管理画面のヘルプ (「アバターとモデル生成」) を見てください。

より自然に・細かく動かしたい場合は、VRM / Live2D のモデルがおすすめです。

## 必要に応じて用意するもの

| もの | 使う場面 |
|---|---|
| 音声合成 (どれか 1 つ) | キャラクターの声。既定は [AivisSpeech](https://aivis-project.com/) (無料・パソコンで動く) ですが、ほかに次のものも選べます。<br>・パソコンで動くもの: VOICEVOX / Irodori-TTS / Style-Bert-VITS2 など<br>・クラウドのもの (API キーが必要): Aivis Cloud API / OpenAI / ElevenLabs など |
| LLM (どれか 1 つ) | 会話。既定は Google Gemini (無料の API キーで使える) ですが、ほかに次のものも選べます。<br>・クラウドのもの (API キーが必要): OpenAI / Anthropic Claude など<br>・パソコンで動くもの (API キー不要): Ollama / LM Studio などの OpenAI 互換 |
| [OBS Studio](https://obsproject.com/) | OBS で配信する場合 |
| [ffmpeg](https://ffmpeg.org/download.html) | OBS を使わず、内蔵の「スタジオ」から配信・録画する場合 |

音声合成と LLM は、管理画面の設定でいつでも切り替えられます。普段使っているものがあれば、それをそのまま使ってください。

## テストへのご協力のお願い

AITuber-Go はまだテスト版で、作者の手元では試せていない環境や使い方がたくさんあります。使ってみた感想や報告をいただけると、とてもうれしいです。

**特に助かること**
- **Mac・Linux での動作報告**: 「起動して管理画面が開いた」だけでも大歓迎です。動かなかったときは、どこで止まったかを教えてください
- **不具合の報告**: おかしな動きや、エラーの表示
- **使いにくいところ・分かりにくいところ**: 画面や説明で迷った点

報告は、このリポジトリの [Issues](../../issues) からお願いします。次のことを書いていただけると助かります。
- お使いのパソコン (Windows / Mac / Linux とそのバージョン)
- アプリのバージョン (Releases のファイル名、または管理画面の左下)
- 何をしたら、どうなったか
- 起動したときの黒い画面 (ログ) に出たメッセージ

⚠️ API キー・配信キー・パスワードなどの秘密の情報は、書き込まないでください (ログやスクリーンショットを貼るときは、念のため映っていないか確かめてください)。
